## Josiah Otto Ephraim

I came to software from mechanical engineering, and spent the last two years

### Shipped

**OneHuman** · a personal safety product I built end to end and run as the only
engineer on call: React Native client, Python FastAPI backend, AWS infrastructure
across EC2, DynamoDB and SNS. Ran a TestFlight beta with 100+ testers and turned
32 actionable items into a prioritised backlog.

**Lift occupancy classification** · a computer vision platform delivered to a
commercial client at RidwanTech, fusing ResNet18 depth-map features with 8
engineered geometric features from MiDaS depth estimation, benchmarked at 57.5ms
mean and 59.5ms p95 inference per frame on CPU. Found a 99.95% validation
accuracy was inflated by augmented copies and temporally adjacent frames
appearing on both sides of the split, and specified building-level holdout
instead. Led a two-person team through to handover.

**josyote.com** · a live art platform with an interactive WebGL gallery, built
and deployed on my own. Held initial JavaScript to ~190KB gzipped on every
non-3D page by isolating the 239KB three.js bundle behind a route-scoped
dynamic import.
